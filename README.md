## 🚦 Multi-Level Drive Health Status

Instead of reducing storage health to a simple working/not-working condition, DriveDx can distinguish several states. 🔎

| 🚦 Status      | 🧠 Meaning                                                                     |
| -------------- | ------------------------------------------------------------------------------ |
| 🟢 **OK**      | ✅ No significant problem detected by the available indicators                  |
| 🟡 **Warning** | ⚠️ An indicator has moved outside its normal condition                         |
| 🟠 **Failing** | 🚨 A pre-failure condition has been detected                                   |
| 🔴 **Failed**  | 🛑 The drive has reached a failed state according to the available diagnostics |

> ⚠️ Drive-health diagnostics are indicators rather than a guarantee that a storage device will or will not fail. Important files should always have independent backups. 💾🛡️

## ❓ Frequently Asked Questions

### ❓ What is DriveDx for Mac?

💡 DriveDx is a drive-health diagnostic and monitoring utility for macOS that analyzes supported SSD and HDD health information.

### ❓ Does DriveDx monitor SSDs?

🔋 Yes. It supports SSD diagnostics and can provide an SSD lifetime-left indicator when the required drive information is available.

### ❓ Does DriveDx support HDDs?

💿 Yes. DriveDx supports HDD diagnostics and applies HDD-specific health evaluation routines.

### ❓ Can DriveDx detect possible drive problems?

⚠️ It monitors health indicators and can alert users when monitored conditions deviate from expected states.

### ❓ Can DriveDx monitor drive temperature?

🌡️ Yes. Temperature monitoring is one of the supported diagnostic features.

### ❓ Can DriveDx monitor free storage space?

💾 Yes. DriveDx can monitor free space and alert users when a configured threshold is exceeded.

### ❓ Does DriveDx support Apple Silicon?

🍎 Yes. Native Apple Silicon support was added in DriveDx 1.12.0.

### ❓ Can DriveDx create reports?

📑 Yes. DriveDx can save drive-health reports and supports automatic email reports.

### ❓ Does DriveDx work with external drives?

🔌 Yes, although the available diagnostics depend on the connection and enclosure. BinaryFruit specifically documents eSATA and Thunderbolt support, while some USB/FireWire setups require an additional driver.

### ❓ Does DriveDx guarantee that a drive will not fail?

🛡️ No. Drive-health monitoring provides diagnostic indicators and warnings; it should be used alongside reliable backups rather than as a guarantee against data loss.
